Pertanyaan Sering Diajukan

Petunjuk instalasi untuk macOS & Windows serta info seputar lisensi dan penggunaan Picdrop.

Bagaimana cara membuka & install Picdrop di macOS? (Unsigned App / Gatekeeper Warning)

Karena Picdrop versi ini belum pakai sertifikat Notarisasi Apple Developer ID berbayar, macOS Gatekeeper mungkin menampilkan pesan seperti:

"Picdrop Upload Assistant is damaged and can't be opened. You should move it to the Trash" atau "Unidentified Developer".

Solusi paling cepat (via Terminal):

  • Seret Picdrop Upload Assistant.app dari file .dmg ke folder Applications.
  • Buka Terminal (⌘+Spasi, ketik "Terminal", Enter).
  • Salin dan jalankan perintah berikut:
xattr -cr "/Applications/Picdrop Upload Assistant.app"

Perintah di atas menghapus tanda karantina macOS. Setelah itu, klik 2x aplikasi Picdrop untuk langsung menggunakannya.

Metode alternatif (tanpa Terminal):

  • Klik kanan (Right-Click) pada Picdrop → pilih Open → klik Open Anyway pada pop-up konfirmasi.
  • Atau buka System Settings → Privacy & Security → scroll ke bagian Security → klik Open Anyway.
Bagaimana cara install Picdrop di Windows?

Download installer .exe, lalu buka file yang sudah kedownload. Kalau muncul "Windows protected your PC", klik More info lalu Run anyway — ini normal, bukan virus, cuma karena aplikasi belum didaftarkan ke Microsoft. Ikuti wizard instalasi, lalu masukkan kode lisensi saat aplikasi pertama kali dibuka.

Satu lisensi bisa dipakai di berapa perangkat?

Satu kode lisensi terkunci ke satu perangkat. Kalau ganti laptop atau install ulang OS, hubungi admin via WhatsApp untuk bantuan pemindahan lisensi — sisa masa berlaku tetap dilanjutkan, tidak mulai dari nol (pasang Picdrop versi terbaru di laptop barumu lebih dulu). Cadangan aktivasi juga tersimpan di Windows Registry, jadi lisensi tidak gampang hilang gara-gara aplikasi cleaner.

Koneksi internet sempat putus saat upload, apa yang terjadi?

Picdrop otomatis mencoba ulang foto yang gagal hingga 40x dalam beberapa ronde, dengan jeda yang makin panjang. Kamu tidak perlu mengulang upload dari awal — cukup biarkan app berjalan, sisanya ditangani otomatis.

Apakah foto yang sama bisa ke-upload dua kali?

Tidak. Picdrop menghitung sidik jari (hash) dari file asli sebelum upload jalan, jadi foto yang sudah pernah diunggah otomatis dilewati — komisi kamu aman, tidak terpotong dua kali untuk foto yang sama.

Mau coba dulu — trial 2 hari perlu kartu kredit?

Tidak perlu. Chat admin via WhatsApp untuk minta trial 2 hari, tanpa kartu kredit dan tanpa komitmen. Kalau cocok, tinggal pilih paket lisensi yang sesuai kebutuhan event kamu.
