Cara install di perangkat kamu

Panduan lengkap langkah demi langkah untuk Windows, Mac Intel, dan Mac Apple Silicon — termasuk cara mengatasi peringatan keamanan yang sering muncul.

Windows

1

Download & buka file

Download installer Windows di atas, lalu buka file .exe yang sudah kedownload.

2

Izinkan instalasi

Kalau muncul "Windows protected your PC", klik "More info" lalu "Run anyway". Ini normal, bukan virus — cuma karena aplikasi belum didaftarkan ke Microsoft.

3

Ikuti wizard instalasi

Pilih folder instalasi (atau biarkan default), klik Install, tunggu sampai selesai.

4

Aktivasi lisensi

Buka aplikasinya, masukkan kode lisensi yang sudah kamu dapat dari admin.

Mac Intel

1

Download & buka file

Download file .dmg Mac Intel di atas, double-click untuk membukanya.

2

Seret ke Applications

Di jendela yang muncul, seret ikon Picdrop ke folder Applications.

3

Izinkan buka pertama kali (Terminal)

Kalau muncul peringatan "...will damage your computer...", itu bukan virus — cuma karena aplikasi belum terdaftar di sistem verifikasi resmi Apple. Buka Terminal (tekan ⌘+Spasi, ketik "Terminal", Enter), lalu paste perintah ini dan tekan Enter:

xattr -cr "/Applications/Picdrop Upload Assistant.app"

Kalau diminta password Mac, ketik passwordnya (huruf tidak terlihat saat diketik, itu normal) lalu tekan Enter.

4

Aktivasi lisensi

Masukkan kode lisensi yang sudah kamu dapat dari admin.

Masih muncul peringatan? Buka folder Applications, klik kanan (atau Control+klik) ikon Picdrop → pilih "Open" → klik "Open" lagi di dialog konfirmasi.
